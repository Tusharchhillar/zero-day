About RED TEAM OPS

Part of the ZERO-DAY SIH2026 project — AI-Based Detection of Cyber Threats in Unidirectional IP Traffic.

🎯 What This Lab Does

The Security Lab simulates real-world attack traffic against a mock government gateway (ApexGov Treasury). Every exploit request is:

  • Processed by the mock gateway's vulnerable endpoints
  • Logged to a SQLite cold-store via a passive tap middleware
  • Pushed as flow metadata to the ZERO-DAY detection engine
  • Detected and classified by both rule-based and NJ-ODE AI layers
  • Displayed as alerts on the SOC Dashboard in real time

🏗️ Architecture

This lab is part of a 3-service stack:

  • mock-target :5000 — ApexGov gateway + Security Lab + exploit endpoints
  • zero-day API :9000 — FastAPI detection engine (rules + NJ-ODE)
  • SOC Dashboard :5173 — React/TypeScript real-time alert viewer

All services bind 0.0.0.0 for LAN access.

🔬 Detection Pipeline

Attack requests flow through the detection engine via two layers:

  • Layer 1 (Rules): 6 rule-based detectors at 40K evt/s — catches known patterns
  • Layer 2 (NJ-ODE): Neural Jump ODE unsupervised anomaly model — catches zero-day attacks

Channel attribution identifies which feature (IAT, bytes, entropy, burst, direction) caused the anomaly.
